## 2. Ranked Non-Model Blockers

### Rank 1 (Critical — Correctness & Traceability, `FR-03`) — `order_context` Field Truncation & Citation Mis-Attribution
- **Requirements Impacted:** `FR-03` (grounded drafts using order facts), `CHỦ ĐỀ 1` priority #1 (`Correctness`) & #2 (`Traceability`).
- **Evidence:**
  - [`apps/backend/tickets/service.py:37-43`](../../apps/backend/tickets/service.py#L37-L43) sends `6` fields: `order_status`, `order_total`, `shipping_cost`, `shipment_status`, `refund_status`, `refund_amount`.
  - [`apps/ai_service/main.py:38-40`](../../apps/ai_service/main.py#L38-L40) validates `10` allowed fields (`order_status`, `placed_at`, `order_total`, `shipping_cost`, `shipment_status`, `estimated_delivery_at`, `delivered_at`, `refund_status`, `refund_amount`, `refund_requested_at`).
  - Yet [`apps/core_backend/llm/gemini.py:485-495`](../../apps/core_backend/llm/gemini.py#L485-L495) (`build_grounded_sources`) and [`gemini.py:535-536`](../../apps/core_backend/llm/gemini.py#L535-L536) (`prepare_llm_input`) use divergent legacy allowlists that **drop `shipment_status`, `order_total`, `shipping_cost`, `refund_amount`, and all `4` date fields**. Confirmed in `probe_results.json`: `prompt_order_facts_fields = ["order_status", "refund_status"]`.
  - Furthermore, [`apps/ai_service/engine.py:279-286`](../../apps/ai_service/engine.py#L279-L286) loops only `for field in ("order_status", "refund_status"):` when mapping non-policy citations (`pg_and_contract_probe.json`: citing `order_facts` emitted `citation_id="S2_order_status"` even when `shipment_status="delayed"` was queried; if `order_status` and `refund_status` are absent, line 285-286 fails closed with `grounding_failed`).
- **Failing Scenario:** Customer asks `"My parcel is delayed — how much was my shipping/refund?"` on an order with `shipment_status="delayed"`, `refund_amount=499000 VND`. The LLM never sees `shipment_status` or `refund_amount`, cannot answer without guessing or asking the customer for data already in `Order`, and any `[S2]` order citation renders `order_status` instead.
- **Smallest Fix:** Align `build_grounded_sources` and `prepare_llm_input` with `SuggestionRequest.check_context`'s identifier-free fields (formatting nested money objects cleanly and excluding PII/IDs), and map `order_context` citations dynamically in `Engine.draft` for all present allowed fields matching [`jobs.py:175-177`](../../apps/backend/tickets/jobs.py#L175-L177).
- **Validation:** Engine + `prepare_llm_input` test with 6-field `order_context` verifying zero identifiers in prompt, all 6 fields available in `S2`, and accurate `order_context` citation rendering.

### Rank 2 (Critical — Reliability & `p95 <= 12s` SLA) — Provider Latency/Timeout Pressure + Serial `SuggestionWorker` + Duplicate `_analyse`
- **Requirements Impacted:** `CHỦ ĐỀ 1` Latency (`p95 <= 12s`) & System Reliability (`FR-03` availability).
- **Evidence:**
  - [`apps/ai_service/drafting.py:38-42`](../../apps/ai_service/drafting.py#L38-L42): `budget_seconds=10.0`, `attempt_timeout_seconds=5.0`, `max_attempts=2`. Real Gemini calls hit `4.66–5.11s` failures on `4/4` initial attempts (`live_ff0e147_oracle_20261113`: `p50=9.93s, max=10.15s`), and `gemini-4-hydrogen` took `12.8746s` to return `503` (`hydrogen_no_read_timeout_20261113/trial.json`).
  - [`apps/backend/tickets/jobs.py:92-119, 182-227`](../../apps/backend/tickets/jobs.py#L92-L119) + [`apps/backend/platform/config.py:24-26`](../../apps/backend/platform/config.py#L24-L26): `SuggestionWorker` runs **one single daemon thread** polling every `500ms`, executes **two** blocking `httpx.Client` calls (`/v1/analyses` `3s` timeout, then `/v1/drafts` `11s` timeout), and [`apps/ai_service/engine.py:196-197`](../../apps/ai_service/engine.py#L196-L197) calls `_analyse(request)` a **second time** inside `Engine.draft()`. Also, [`jobs.py:133`](../../apps/backend/tickets/jobs.py#L133) only retires a crashed/expired `20s` lease on the 4th claim (`>= 60s`).
  - Local CPU cost of `_analyse` (`p50=29.34ms`, `p95=36.70ms`) + duplicate `_analyse` (`p50=29.95ms`, `p95=36.45ms`) is small (~`60ms`), so **queue serialization + external provider latency** dominate tail latency.
- **Failing Scenario:** 3 tickets arrive concurrently while Gemini triggers a `5s` timeout + retry (`10s`). Ticket 1 finishes near `10.5–11.5s`; Ticket 2 waits `~10s` in queue + `10s` LLM (`~20s`), and Ticket 3 waits `~20s` (`~30s`), breaking `p95 <= 12.0s`.
- **Smallest Fix:** Use a bounded worker pool (e.g., `ThreadPoolExecutor(max_workers=4)` leveraging existing `FOR UPDATE SKIP LOCKED`) with shared `httpx.Client` pooling, pass/accept pre-computed analysis or consolidate into one `/v1/drafts` pass when drafting, and add a short-lived circuit breaker on repeated `llm_timeout`/`503` failures.
- **Validation:** Concurrent `10`-ticket benchmark against a deterministic `5s`-delayed transport proving parallel completion within SLA and idempotent single-suggestion updates.

### Rank 3 (High — Safety/Grounding False Positives, `FR-03`) — Over-Broad `_UNCITED_CLAIM_TERMS` Rejecting Valid Polite Framing
- **Requirements Impacted:** `FR-03` (draft generation usability & rate), `CHỦ ĐỀ 1` Reliability.
- **Evidence:** [`apps/core_backend/safety.py:406-413, 491-505, 677-682`](../../apps/core_backend/safety.py#L406-L413) (`_is_safe_uncited_sentence`) flags any uncited sentence containing `order`, `delivery`, `refund`, `return`, `policy`, `within`, etc. Confirmed in `pg_and_contract_probe.json`: `"Thank you for reaching out about your order.\n\nCustomers may return products within 30 days of delivery [S1]."` and `"...\n\nPlease let us know if you have questions about this policy."` both fail with `"uncited_claim"` -> `llm_invalid_citations` / `grounding_failed` (`llm_unavailable`).
- **Failing Scenario:** Gemini produces an accurate, cited policy answer (`[S1]`) with a polite greeting mentioning `"your order"` or closing mentioning `"this policy"` without `[S1]` on that greeting; SupportIQ discards the entire draft.
- **Smallest Fix:** Allow non-factual polite acknowledgments/closings (matching explicit greeting/thank-you/invitation patterns without numbers, conditions, or transaction commitments) OR prompt-align `SYSTEM_PROMPT` to omit uncited framing containing policy/order nouns.
- **Validation:** Grounding unit suite confirming polite greetings/closings pass while uncited factual claims (`"Your order ships free"`, `"Returns take 5 days"`) still fail closed.

# SupportIQ Docker Packaging Plan & Checklist

**Date:** 2026-11-15  
**Scope:** Real Linux Docker Compose runtime on branch `minh`, preserving native startup, `.local/`, core runtime contracts, and local models/datasets.

## Design Decisions (Ponytail ULTRA)

- **Services (`compose.yaml`):**
  - `postgres` (`postgres:16-alpine`): Internal network only (no host ports), persistent named volume `pgdata`, owner role `supportiq_owner`.
  - `init` (`target: backend`, `restart: "no"`): Waits for `postgres` healthy; validates required DB + demo account passwords; provisions/syncs restricted `supportiq_app` role (`NOSUPERUSER NOCREATEDB NOCREATEROLE`); writes container-scoped `SUPPORTIQ_APPLICATION_SECRETS` JSON (`/run/supportiq/application.json`, never `.local/application.json`); invokes `apps.backend.manage.initialize()` (Alembic migrations + table/sequence `GRANT`s + first-start-only `seed()`).
  - `ai-service` (`target: ai-service`, `restart: unless-stopped`): Non-root Python 3.12-slim with CPU PyTorch (`whl/cpu`) + existing `pipeline/requirements-transformers.txt` + FastAPI runtime. Internal network only (`8002`). Read-only mounts for `reconstructed-fit2-supcon-20261113` and host Hugging Face cache (`BAAI/bge-small-en-v1.5`) with `HF_HUB_OFFLINE=1` & `TRANSFORMERS_OFFLINE=1`. LLM defaults to `gemini-3.5-flash-lite` (`SUPPORTIQ_ENABLE_LLM=true`, `SUPPORTIQ_MAX_LIVE_LLM_REQUESTS=2`, `SUPPORTIQ_LLM_MAX_ATTEMPTS=1`, runtime-injected `GEMINI_API_KEY`). Healthcheck asserts `status == "ready"`, `retrieval_ready is True`, `model_verified is True`, and pinned Fit2/calibration SHA-256 digests.
  - `backend` (`target: backend`, `restart: unless-stopped`): Non-root Python 3.12-slim + multi-stage React SPA (`node:24-slim` + `pnpm@10`). Bound strictly to `127.0.0.1:${SUPPORTIQ_HOST_PORT:-8081}:8080` so native `:8080` stays untouched. Connects solely as restricted `supportiq_app` via URL-escaped DSN, `depends_on` `init` (`service_completed_successfully`) and `ai-service` (`service_healthy`), enforces `SUPPORTIQ_REQUIRE_PRIVACY_NER=true`, `SUPPORTIQ_ALLOWED_ORIGINS` for `:8081`, and `SUPPORTIQ_SESSION_COOKIE_SECURE=false` for local HTTP.
- **Image & Context Hygiene (`.dockerignore`):**
  - Strict allowlist (`*` baseline) excluding `.env`, `.env.*`, `.local/`, `.git/`, `.venv/`, `data/datasets/`, `artifacts/`, caches, `tests/`, and `docs/`. Includes only required `apps/{backend,ai_service,core_backend,ml_inference,frontend}`, `pipeline/requirements-transformers.txt`, `data/knowledge/approved_kb.v2.json`, and `data/knowledge/mock_orders.json`.

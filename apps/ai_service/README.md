# SupportIQ stateless AI gateway

This local HTTP boundary adapts the existing verified inference model, approved KB retriever, and Gemini client to `/v1/analyses`, `/v1/drafts`, `/v1/asset-versions`, and versioned KB reads. It owns no tickets, sessions, orders, database, or per-ticket state. The application backend calls it with pseudonymized text and identifier-free order fields.

Native startup runs it on `127.0.0.1:8002`, using offline model caches. Model load failures fail closed and return unavailable outcomes instead of synthetic predictions. In the absence of verified artifact metadata, provenance defaults to `model_mode="unknown"` and `verified=False`; trusted status is never assumed from missing fields. If explicit demo fallback is active, it carries `model_mode="heuristic_demo"` and `verified=False`, and the gateway cannot certify it as verified trained readiness. Staff intent overrides are recorded with `source="staff"`, `score_kind="staff_choice"`, and `model_mode="override"`, and never masquerade as verified model predictions. The gateway applies the existing per-intent routing thresholds and requests intent confirmation only below those thresholds. The application preserves manual support throughout an AI failure.

External generation uses a local `GEMINI_API_KEY` by default; start with `-DisableLLM` to disable it. An HTTP transport allows only HTTPS calls to `generativelanguage.googleapis.com`; provider responses and keys are not logged. The standard test suite excludes external generation. Run `python scripts/verify_ai_integration.py` explicitly to verify the complete live application flow in an isolated schema. Model scores, policies and source IDs are never fabricated.

The gateway validates citation identity, placeholder provenance, and structural paragraph-level grounding around the draft client. Uncited paragraphs with prominent factual commitments (monetary amounts, return windows, timeframes) fail grounding, while harmless conversational greetings, sign-offs, and clarifications are permitted. These regex checks are structural heuristics only and are not a comprehensive detector of all uncited factual claims; they do not establish semantic entailment. Human review remains mandatory for all customer-facing replies. The existing model/retrieval calibration and grounding evaluations remain separate release gates.
